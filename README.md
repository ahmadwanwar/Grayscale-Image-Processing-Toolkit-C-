# Grayscale-Image-Processing-Toolkit-C-
This project is a comprehensive image processing toolkit built from scratch in C++ without external libraries. It allows users to load, manipulate, and save grayscale images through an interactive menu system. The application includes operations such as brightness adjustment, contrast stretching, rotation, scaling, flipping, cropping, filtering (mean, median, and custom kernels), edge detection using Sobel operators, and image combination.

It demonstrates strong understanding of image representation, matrix manipulation, and core digital image processing techniques, along with file handling and modular program design.
